# Image assets

These SVG illustrations are original, locally stored assets made for this starter portfolio:

- `hero-workspace.svg` — hero visual
- `project-css.svg` — CSS effects thumbnail
- `project-grace.svg` — biography page thumbnail
- `project-layout.svg` — layout/Bootstrap thumbnail

If your instructor expects a personal photo, replace the hero illustration with a photograph you own or have permission to use. Crop it to a suitable portrait or landscape shape and update the `img` path and alt text in `index.html`.
