# Portfolio image assets

These four original SVG illustrations are used by `index.html`:

- `hero-workspace.svg` — hero section workspace illustration
- `project-css.svg` — CSS effects project card
- `project-grace.svg` — biography project card
- `project-layout.svg` — responsive layout project card

Keep these files inside the `assets` folder when uploading the website. File names are case-sensitive on GitHub Pages.
